# Environment Configuration

## Setup Instructions

1. Copy `.env.example` to `.env`:
   ```bash
   copy .env.example .env
   ```

2. Edit `.env` and add your Google Apps Script URL:
   ```
   APPS_SCRIPT_URL=your_actual_script_url_here
   ```

3. The `.env` file is gitignored and will not be committed to version control.

## Deployment

Follow the instructions in `server/code.gs` to deploy your Google Apps Script and obtain the Web App URL.
